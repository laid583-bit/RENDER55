# Project Summary
The project is a secure web application designed for managing financial transactions across various cryptocurrencies, including TTBTOKEN, TRX, and USDT on the Tron network. It aims to deliver a secure and user-friendly experience while allowing customizable transaction fees. The platform features a modular architecture for currency conversion and transaction processing, alongside advanced admin functionalities for permission management and oversight. Users can gain insights into profits and fees through a dynamic liquidity and profit system, with comprehensive support for multiple payment methods, including the newly integrated Redotpay, Binance Pay, Wise, and Stripe.

# Project Module Description
The main functional modules of the application include:
- **Deposit Module**: Users can deposit funds through various payment gateways, including Redotpay, Binance Pay, Wise, and Stripe.
- **Withdraw Module**: Facilitates withdrawals with balance checks and transaction history, supporting multiple payment methods.
- **Wallet Module**: Integrates with wallet services like TronLink and MetaMask.
- **Currency Converter Module**: Enables conversion between TTBTOKEN, TRX, USDT, and other currencies.
- **Bot Conversions Module**: Automates currency conversions and integrates with Telegram for real-time updates.
- **Admin Module**: Manages transaction fees, currency pairs, and settings with enhanced permissions management.
- **Profits Module**: Displays bot conversion data, including total profits and fees.
- **Pool Wallet Module**: Manages liquidity and validates transactions against the pool wallet address.
- **Bank Requests Module**: Handles bank deposit and withdrawal requests with an alerts system for pending requests.

# Usage
1. Install dependencies for the frontend:
   ```bash
   pnpm install
   ```
2. Build the frontend project:
   ```bash
   pnpm run build
   ```
3. Install dependencies for the bot:
   ```bash
   cd app/bot
   npm install
   ```
4. Run the bot and API server together:
   ```bash
   node server.js
   ```
5. For production deployment, use PM2:
   ```bash
   pm2 start ecosystem.config.js
   ```
