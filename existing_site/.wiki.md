# Project Summary
TTB Exchange is a sophisticated currency exchange platform that offers real-time pricing, deposit and withdrawal functionalities, and advanced trading capabilities for both individual and institutional users. It enhances the trading experience through a seamless user interface and robust backend. Recent updates have integrated BaridiMob, improved the sub-admin management system, expanded payment methods, and added support for new cryptocurrencies, including USDT, BTC, and ETH.

# Project Module Description
The project consists of two main modules: backend and frontend.

## Backend
- **Core Services**: Manages authentication, database operations, and configuration settings.
- **Data Models**: Structures for currency pairs, deposits, withdrawals, user balances, expert tasks, and sub-admins.
- **Routers**: API endpoints for functionalities like payments, user management, and expert trading tasks.
- **Dependencies**: Reusable components and authentication mechanisms.
- **Schemas**: Data validation and serialization formats.
- **Rates Service**: Fetches and manages market rates for various currencies.

## Frontend
- **Components**: UI elements such as buttons, forms, and modals.
- **Pages**: User interaction views, including the main dashboard, transaction history, admin controls, and sub-admin management.
- **Converter**: Page for converting between currencies, now includes support for USDT and other cryptocurrencies.
- **Hooks**: Custom React hooks for state management and API interactions.
- **Styles**: CSS and Tailwind configurations for responsive design.
- **Deposit & Withdraw Pages**: Now support USDT, BTC, and ETH as payment methods.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic for database migrations.
- **Frontend**: React, TypeScript, Vite, Tailwind CSS for styling.

# Usage
To set up the project, follow these steps:
1. **Install Dependencies**:
   - Navigate to the backend directory and run `pip install -r requirements.txt`.
   - Navigate to the frontend directory and run `npm install`.
   
2. **Build the Project**:
   - For the backend, run `alembic upgrade head` to apply database migrations.
   - For the frontend, run `npm run build` to bundle the application.

3. **Run the Application**:
   - Start the backend server with `uvicorn main:app --reload`.
   - Start the frontend development server with `npm run dev`.
