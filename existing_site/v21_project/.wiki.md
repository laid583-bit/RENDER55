# Project Summary
TTB Exchange is a personal currency conversion platform designed to facilitate real-time currency exchanges and streamline financial transaction management. The platform offers an intuitive interface for accurate currency conversions, transaction histories, and various electronic payment options. Key features include profit tracking, a comprehensive earnings withdrawal system, effective deposit management, and support for multiple cryptocurrencies, commodities, and stocks. Recent updates have introduced reverse conversion capabilities, percentage-based fee structures, and enhanced user flexibility with multiple currency pairs. A new alert system for percentage changes in currency pairs has also been implemented.

# Project Module Description
The project consists of several functional modules:
- **Currency Conversion**: Manages conversion rates and currency operations, supporting bidirectional conversion with updated logic for buy/sell prices. Now includes new cryptocurrencies, commodities, and stocks.
- **User Balances**: Tracks user balances and transaction histories.
- **Payments**: Facilitates processing of payments and deposits.
- **Health Check**: Provides endpoints for system health monitoring.
- **Data Models**: Contains JSON files for storing conversion rates, deposits, and fee settings.
- **Services**: Implements business logic for user management and currency handling.
- **Frontend Components**: A collection of reusable UI components for building the user interface.
- **Banks Page**: Lists electronic banks and payment gateways with logos and descriptions.
- **Profits Page**: Displays profit summaries, histories, and earnings details.
- **Withdraw Page**: Clearly displays all withdrawal methods for easy access.
- **Deposit Page**: Manages deposits with various electronic banks and payment methods.
- **Admin Dashboard**: Interface for managing withdrawal and deposit requests, now updated to use only percentage-based fees.
- **Converter Page**: Displays accurate conversion amounts after fee deductions, including price charts, alerts, and a new feature for percentage-based alerts when both currencies rise.
- **History Page**: Displays all previous conversions with filtering options by currency pair and date, along with data export capabilities.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic for database migrations.
- **Frontend**: React, TypeScript, Tailwind CSS for styling and layout.
- **Database**: PostgreSQL (or similar relational database).

# Usage
To get started with the project:
1. Install backend dependencies:
   ```bash
   pip install -r app/backend/requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   pnpm install
   ```
3. Run database migrations:
   ```bash
   alembic upgrade head
   ```
4. Build and run the frontend application:
   ```bash
   pnpm run build
   pnpm start
   ```
