الخطوة التالية مباشرة هي مراجعة وتعديل ملف استقبال البيانات (الـ API PHP) الذي يربط بين البوت والموقع (غالباً ما يكون اسمه api.php أو ما يشابهه).
بما أن المبرمجين جهزوا لوحة التحكم وقاعدة البيانات، يجب الآن حقن المعادلات الجديدة داخل هذا الملف لتبدأ الواجهة البرمجية بالعمل الفعلي وقشط الأرباح ديناميكياً مع كل حركة قادمة من البوت.
لضمان أعلى درجات الدقة وصِفر أخطاء، اطلب من المبرمجين تزويدك بكود ملف استقبال البيانات الحالي (الـ API)، أو اطلب منهم تطبيق التعديل الصارم التالي على ذلك الملف:
🚀 التوجيه التقني للخطوة الثانية: تعديل ملف استقبال البيانات (api.php)
يرجى فتح ملف الـ API المسؤول عن استقبال حركات البوت، وتحديث منطق معالجة المعاملة المالية ليعتمد على القيم الحية المستدعاة من قاعدة البيانات كالتالي:
1️⃣ أولاً: استدعاء الإعدادات الحية من قاعدة البيانات
في بداية الدالة المسؤولة عن معالجة الطلب القادم (بعد التحقق من هوية البوت وتأمين الطلب)، يتم جلب المتغيرات الديناميكية التي تم تأسيسها في لوحة التحكم:
PHP	
// جلب القيم الحية المحددة من قِبل الإدارة لمنع تثبيت الأرقام في الكود
$query_settings = mysqli_query($conn, "SELECT `target_spread`, `admin_gas_fee` FROM `system_config` WHERE `id` = 1 LIMIT 1");
$settings = mysqli_fetch_assoc($query_settings);

$target_spread = (float)$settings['target_spread']; // فارق السعر المستهدف الصافي
$admin_gas_fee = (float)$settings['admin_gas_fee']; // فارق الغاز الجديد المقتطع من البوت
2️⃣ ثانياً: تطبيق المنطق الحسابي وقشط الأرباح بدقة
عند استلام مبلغ المعاملة الإجمالي القادم من البوت ($incoming_amount)، يتم توزيع الأموال رياضياً بناءً على المعادلة الصارمة التالية:
PHP
// 1. حساب التكلفة الفعلية لاستئجار الطاقة عبر الـ API (مثال: 0.10$)
$actual_api_energy_cost = get_actual_energy_rental_cost(); 
		
// 2. حساب أرباح الغاز الجانبية الصافية (فارق الغاز مطروحاً منه التكلفة الفعلية)
$gas_profit = $admin_gas_fee - $actual_api_energy_cost;

// 3. حساب إجمالي الأرباح الصافية للأدمن الناتجة عن الحركة
$total_pure_profit = $target_spread + $gas_profit;

// 4. ترحيل الأرباح الصافية فوراً وبشكل منفصل إلى جدول أرباح الإدارة
$insert_profit = mysqli_query($conn, "INSERT INTO `admin_profits` (`amount`, `type`, `created_at`) VALUES ('$total_pure_profit', 'bot_skimming', NOW())");
3️⃣ ثالثاً: تدوير المتبقي الآمن في حوض السيولة
لضمان استمرار الحركات الـ 4000 يومياً دون توقف الحوض، يتم ترحيل الجزء النظيف فقط من الحركة إلى حوض السيولة الرئيسي الحاضن للموقع:
PHP
// حساب المبلغ المتبقي بعد قشط فارق السعر وفارق الغاز بالكامل
$clean_pool_amount = $incoming_amount - ($target_spread + $admin_gas_fee);

// تحديث رصيد حوض السيولة (Liquidity Pool) بالمبلغ المتبقي النظيف فقط
$update_pool = mysqli_query($conn, "UPDATE `liquidity_pools` SET `balance` = `balance` + '$clean_pool_amount' WHERE `id` = 1");
