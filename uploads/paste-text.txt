توجيه تقني محكم ومحدد لتعديل نظام السيولة والأرباح ديناميكياً
يرجى الالتزام التام بالتسميات والمنطق البرمجي التالي لضمان عدم حدوث أي تضارب بين الموقع والبوت:
1️⃣ أولاً: تحديث قاعدة البيانات (Database Schema Update)
إضافة حقول ديناميكية مرنة من نوع DECIMAL(10,2) لضمان قراءة الأرقام الحية بدقة بدون أي تقريب حسابي خاطئ:
SQL	
ALTER TABLE `system_config` ADD COLUMN `target_spread` DECIMAL(10,2) DEFAULT '50.00';
ALTER TABLE `system_config` ADD COLUMN `admin_gas_fee` DECIMAL(10,2) DEFAULT '1.00';
2️⃣ ثانياً: تحديث واجهة لوحة التحكم (Admin Panel Interface)
إضافة حقلين مرنين لاستقبال المدخلات من الإدارة، مع تغيير المسميات القديمة لضمان الوضوح:
•	الحقل الأول: يسمى "فارق السعر المستهدف الصافي ($)" -> يُربط برمجياً بالمتغير والعمود target_spread.
•	الحقل الثاني: يتم تعديل مسماه القديم (الخصم على الرسوم) ليصبح "فارق الغاز ($)" -> يُربط برمجياً بالمتغير والعمود admin_gas_fee (يجب أن يقبل هذا الحقل قيم مرنة ترتفع وتتغير ديناميكياً حتى 100$ وأكثر حسب حاجة الإدارة).
3️⃣ ثالثاً: المنطق الحسابي الدقيق داخل ملف الـ API المستقبِل لحركات البوت (api.php)
تعديل الدالة المسؤولة عن معالجة المعاملات لتعتمد على المعادلات الديناميكية الجافة (Dynamic Logic) بدلاً من أي أرقام ثابتة في الكود لمنع الأخطاء البرمجية. المنطق الحسابي الصارم لكل حركة هو كالتالي:
PHP
// 1. استدعاء القيم الحية الحالية من قاعدة البيانات لمنع تثبيت الأرقام
$target_spread = get_system_setting('target_spread'); // القيمة الحية لفارق السعر المستهدف
$admin_gas_fee = get_system_setting('admin_gas_fee'); // القيمة الحية لفارق الغاز الجديد

// 2. المعادلة الحسابية لتوزيع الأموال عند استقبال المعاملة ($incoming_amount)
// حساب أرباح الغاز الجانبية (فارق الغاز المحدد في اللوحة مطروحاً منه التكلفة الفعلية للاستئجار)
$gas_profit = $admin_gas_fee - $actual_api_energy_cost; 

// حساب إجمالي الأرباح الصافية للأدمن (فارق السعر المستهدف + أرباح الغاز الجانبية)
$total_pure_profit = $target_spread + $gas_profit;

// 3. الإجراءات البرمجية الصارمة للتنفيذ:
// أ. ترحيل $total_pure_profit فوراً وبشكل منفصل إلى جدول الأرباح الصافية للأدمن.
// ب. تمرير المتبقي النظيف والآمن فقط [Incoming Amount - (Target Spread + Admin Gas Fee)] إلى حوض السيولة (Liquidity Pool) لضمان التدوير المتوازن والمستمر.
